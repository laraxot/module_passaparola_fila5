# Story 2.3 - Assistente dell'operatore (fase B)

Come operatore voglio chiedere in una chat del pannello di vedere la coda, preparare risposte e
aggiornare la base di conoscenza, confermando io ogni azione che arriva al cliente.

## Criteri di accettazione

- [x] Agente `OperatorAssistant` su `XotBaseAgent` (modulo AI) con gli 8 tool del server MCP, eseguiti in-process
- [x] Conferma obbligatoria su ogni tool non read-only (test che lega le annotazioni MCP alle approvazioni)
- [x] Endpoint `RunOperatorAssistantAction`: sessione, CSRF, limite 30/min, solo membri o amministratori, thread `operator-{utente}-…`
- [x] Pagina Filament "Assistente" (gruppo Passaparola) con suggerimenti, streaming, card di conferma leggibile
- [x] Client JS con `@ag-ui/client`, Markdown sanificato (`@a2ui/markdown-it`), sorgente e build nel modulo
