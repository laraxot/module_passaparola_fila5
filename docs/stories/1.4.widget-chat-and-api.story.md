# Story 1.4 - Widget chat e API

## Criteri di accettazione

- [x] Modelli `ChatWidget` (siti ammessi, chiave pubblica, saluto) e `Conversation` (stato, token del visitatore, thread AI)
- [x] API pubblica: configurazione, invio messaggio, storico; limite di richieste per IP
- [x] Solo i siti ammessi possono usare un widget (header `Origin`); elenco vuoto = nessuno
- [x] Risposta dall'assistente del modulo AI con base di conoscenza e parole sensibili dell'attività
- [x] Dopo il passaggio a una persona le domande non vanno più all'assistente
- [x] Script `public/widget.js` senza dipendenze, accessibile (aria, Esc, focus), testi solo come testo
- [x] Avviso che risponde un'AI sempre visibile
- [x] Risorsa Filament con il codice da incollare
- [x] Test Pest e test JS; screenshot reale del widget nella documentazione
- [x] Modulo AI: `CreateAiThreadAction` e `AppendAiMessageAction` agnostiche (story `assistant-widget-support` del modulo AI)
- [ ] `php artisan migrate`, `pest`, `phpstan` nell'app host
- [ ] Prova reale su un sito esterno con un dominio ammesso
